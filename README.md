tpgit

Project Description : tpgit is a practical software version control project developed as part of the UM6P Computer Science curriculum. The primary goal of this project is to simulate real-world collaborative software development workflows using GitHub. Throughout this project, we explored core software versioning practices, including:
Repository Architecture: Managing local working trees and commit histories.
Branching Strategies: Creating isolated development workflows (vegetables, sauces, spices, herbs) to implement features independently without breaking the master build.
Merge Mechanics: Integrating divergent feature branches into master using both fast-forward and explicit merge commits.

Objectives
* Master the foundational CLI toolkit for Git (status, add, commit, log, diff, branch, checkout, merge).
* Establish structured branch naming and clean commit history maintenance using detailed messages and log.
* Learn remote operations (remote, push, pull,) over secure HTTPS protocols.
